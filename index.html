Understanding ASTC Compression

Adaptive Scalable Texture Compression (ASTC) is an advanced block-based lossy texture compression format developed by ARM and AMD. It is widely used in modern mobile and desktop GPUs.

Key Features of ASTC:

  • Variable Block Sizes: Supports block sizes from 4x4 (8.00 bpp) up to 12x12 (0.89 bpp), allowing developers to trade quality for memory footprint.
  • Color Endpoints & Weights: Each 128-bit block stores two color endpoints and a grid of interpolation weights to reconstruct pixel colors.
  • Dual-Plane Support: Can compress color and alpha channels independently for high-quality transparency.

How this Suite Works:

This application implements a real, fully functional ASTC encoder and decoder in pure JavaScript.

When you Encode an image, it divides the image into blocks, computes the optimal color endpoints, calculates interpolation weights for each pixel, and packs them into a standard-compliant 128-bit ASTC block structure with a valid 16-byte ASTC header.

When you Decode an ASTC file, it parses the binary header, extracts the block dimensions, reads the 128-bit blocks, interpolates the colors using the weight grid, and renders the reconstructed image onto the canvas.
